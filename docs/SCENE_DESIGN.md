## 1. 咖啡桌：建议优先试做

**素材依据：** 当前用户明确提到咖啡馆主题，文件名中也出现咖啡、蛋挞、一质咖啡、如初咖啡及旅行中的咖啡。具体店内空间、杯子、座位和天气尚未核实。

**提案：** 一个小桌面、咖啡杯和两三张照片。轻微转动视角，点照片打开真实照片及一句说明。模型只表达相处的氛围，第一版不复刻整家店。

**需要补充：** 最想留下的是哪一次咖啡；一张桌面或店内参考图；记得的具体小事。若没有足够参考，可以用抽象几何物件，但不得称为真实店面复原。

**静态替代：** 同一组照片按相同顺序排列，保留全部文字。只想看照片的人无需进入场景。

## 2. 高达礼物：一件小物的故事

**素材依据：** 用户提出高达礼物主题；6.27 的素材命名同时提到咖啡和高达扭蛋。它不证明礼物是拼装模型，也不证明具体系列、型号或人物。

**提案：** 一个简单展示台，礼物照片为视觉中心；确认形态后再决定是否做可旋转物件。点击物件只打开真实照片和用户认可的说明，不设计象征“重新在一起”的任务或谜题。

**需要补充：** 实物正面与侧面照片、款式名称、赠送方向、当时为什么选它、用户想记住的一句话。

**建模边界：** 没有合适模型时保留照片或抽象展示台；不要下载来源不明的角色模型。使用外部模型、字体或音乐前记录来源与可用范围。

**静态替代：** 礼物照片和说明卡。

## 3. 曼谷旅行：照片带路

**素材依据：** “曼谷旅游7.31-8.4”主题下共有 26 份 HEIC，文件名涉及城市漫步、咖啡、游船、芭提雅及格兰岛。素材清单的 EXIF 年份为 2026，但完整路线和事件日期仍需核对；一张收获照片的拍摄记录晚于主题日期范围一天。

**提案：** 先做按日或主题排列的旅行相册。后续选择一个真实参考充足的小场景：咖啡桌、船边或明信片陈列。不同城市明确分章，不根据文件夹总标题把旅行全程放在曼谷。

**需要补充：** 确认素材年份与旅行年份对应、补充行程节点、最喜欢的三到五张照片，以及希望保留的一个片段。现有 26 份文件并不等于全部都应展示。

**边界：** 地点未确认前不生成真实路线地图；不要想象酒店房间、对话、天气或当天心情。

**静态替代：** 完整旅行照片章节，3D 只是一处可选入口。

## 4. 日常与照片墙：后续候选

做饭、散步、骑车、猫、花草和小礼物已有命名线索；还有一张被命名为实物照片墙的照片。可以先用普通相册排版体现，不必每一段都做成 3D。

是否把实物照片墙作为站点结构，需要先看实际照片并听用户解释。生日礼物可按用户选择并入物件章节，不自动显示生日日期或未经确认的人物信息。

## 实施顺序

先选一组获准使用的照片 → 写清对应故事 → 做静态章节 → 选一个小场景试做 → 验证手机、键盘和静态回退 → 再决定是否增加第二个场景。

第一场景优先咖啡桌只是本次提案；最终顺序由用户偏好和素材完整程度决定。
