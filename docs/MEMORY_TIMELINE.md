## 新回忆的记录格式

为每个确认后的事件保存：稳定编号、标题、日期或范围、日期精度、用户自己的描述、素材编号、来源类型、确认日期、是否允许进入网站。年份未知就保留未知，不用整理日期补齐。

同一事件可以有多个视角；个人感受写成“我记得”“我当时觉得”，不要改写为对方的心理事实。
