## 作品希望传达什么

让真实照片和具体小事承载回忆：一杯咖啡、散步时留下的一张照片、收到的一件小礼物。表达感谢和纪念，语气平实、有分寸。访客可以自由浏览、跳过和离开，不需要回答任何与关系有关的问题。

成功与否看作品是否忠于记忆、清楚易读、可被长期保存，不以对方是否回应或关系是否改变作为指标。

## 页面叙事提案

| 区域 | 内容 | 互动 |
| --- | --- | --- |
| 开场 | 一张确认可用的照片、OneDay 标题、一句用户认可的开场话 | 直接往下阅读 |
| 回忆目录 | 相遇、咖啡与日常、旅行、礼物等主题 | 跳到章节；日期不完整时仍能按主题看 |
| 照片章节 | 照片与简短说明，有日期才显示日期 | 点开大图、前后切换、返回原位置 |
| 记忆中的物件 | 一个咖啡桌或礼物小场景 | 可轻微转动和点选；旁边始终保留照片入口 |
| 结尾 | 用户自己写的感谢文字 | 平静结束，不安排回复、复合或倒计时 |

不必将所有照片选入第一版。先保留完整素材，再从每个主题挑有代表性的照片，避免删掉原片。文字不足时可以先只有照片，等待用户补充。

## 视觉提案

采用像私人相册一样清楚、安静的排版：暖白或浅灰底、深灰文字、小面积柔和强调色，照片决定主要色彩。保留足够空白，横竖照片按自身比例展示，大图不强裁主体。

字体优先清晰中文正文，标题只作适度变化。避免把整页做成发光爱心、漂浮花瓣或长篇煽情宣言。手写感只适合少量用户亲笔内容或经确认的装饰。

照片墙可参考素材中已有的实物照片墙线索，待看清照片并获用户确认后再决定布局，不能现在就声称已经复刻。

## 交互与可访问性

手机优先：正常竖屏浏览，主要按钮可轻松点按，照片大图有明确关闭入口。键盘可以打开、切换和关闭照片；关闭后焦点回到触发位置。图片说明只写实际可见且获准的信息。

动画应可跳过；系统启用减少动画时关闭大幅位移、持续转动和视差。`prefers-reduced-motion` 可用于响应这种系统偏好，具体动画关闭范围是本项目的设计选择。[MDN：减少动画偏好](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)

音乐未确定。若以后加入，由用户主动播放，并提供随时关闭入口。没有声音或 3D 也能读完全部故事。

## 技术结构提案

检查时仓库为空，因此没有已选框架和安装命令。推荐先保持结构简单：普通页面负责照片与文字，一个独立场景模块承载 3D，内容数据单独维护。是否采用框架由后续实际开发决定，不为本次档案强行引入依赖。

Three.js 是局部 3D 的候选；它用场景、相机和渲染器组织网页 3D 内容。此前对话提过它，但这不等于已经确定框架或完成场景。[Three.js 基础文档](https://threejs.org/manual/pages/fundamentals.html)

建议按需加载场景，静态照片先出现。场景不可用时保留同一段故事和静态图，避免黑屏、空白或必须等待模型。是否加入 React 生态适配层等附加库，只在已有项目选择需要时评估。

图片派生为适合网页的格式和多种尺寸；用 `picture`、`srcset` 等提供候选资源和回退。它们允许浏览器根据设备、显示条件与格式支持选择合适图片。[MDN：picture 元素](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/picture)

建议初期使用静态内容文件维护资料，不加入数据库或内容后台。照片获准公开后可以随站点发布；若最终只允许特定人访问，应在选托管方案前明确访问控制要求，不能把隐藏链接或前端密码当作保护照片的方案。

## 内容数据建议

| 字段 | 用途 |
| --- | --- |
| `id` | 稳定的回忆编号，重命名标题不改变关联 |
| `title` / `caption` | 用户确认的标题和说明 |
| `dateLabel` | 经确认的展示日期；未知可为空 |
| `datePrecision` | 年、月、日、范围或未知 |
| `sortOrder` | 在日期未知时使用人工确认的顺序，不编造 ISO 日期 |
| `chapter` / `assetIds` | 章节及获准使用的素材编号 |
| `verification` | 待确认、用户已确认等事实核查状态 |
| `publicationApproval` | 是否明确获准发布；默认 `false` |

详细来源、原始路径、个人备注保留在本地索引中，不进入网站浏览器可下载的数据。构建只读取允许发布的内容，排除尚未确认的记录。

## 第一版验收

- 不进入 3D，也能看完全部已选照片和说明。
- 手机无横向溢出，图片不会明显变形；横竖图都有合适呈现。
- 照片大图、关闭与焦点返回正常，键盘操作可用。
- 减少动画、场景加载失败时有完整阅读路径。
- 日期不明时不显示伪造日期；没有以助手推断写成的个人故事。
- 网络资源及构建输出中不包含原始私密路径、未批准素材或私人情感记录。

性能数值在真实素材和设备上测量后记录；当前没有运行中的页面，不报告虚构的加载成绩。
